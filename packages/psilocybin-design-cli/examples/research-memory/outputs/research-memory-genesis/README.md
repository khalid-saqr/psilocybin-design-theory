# research-memory Genesis Repo

This repository is a Psilocybin Design genesis-repo. It is not the final software.
It is the agent-readable seed for implementing the software organism described by
the design genome.

## Raw intention

A tool for research teams to remember why decisions were made across papers, experiments, meetings, and code changes.

## Design genome

The system preserves research decision memory by connecting decisions, evidence, actors, status changes, and supersession events so the team can recover why something happened and whether it still holds.

## Start here

Coding agents and human implementers must begin with:

1. `psilocybin.design.yaml`
2. `DESIGN.md`
3. `IMPLEMENTATION_SEQUENCE.md`
4. `SURVIVAL_TESTS.md`

Do not begin from framework defaults, feature assumptions, or generic boilerplate.
