# Stack Rationale

## Selected stack

- Name: FastAPI + PostgreSQL + React
- Language: Python and TypeScript
- Storage: PostgreSQL
- Interface: Web UI and HTTP API
- Deployment: Containerized deployment
- Observability: Structured logs and audit events
- Tests: Pytest and frontend tests plus survival tests

## Rationale

Relational traceability, provenance, statuses, and multi-actor audit are central to the genome.

- Local Markdown + SQLite
