# Paper source

Canonical LaTeX source for **Psilocybin Design: A Theory-Method for Deriving Software Organisms from Gaps**.

- `Psilocybin_Design_Theory_Complete.tex`: publication source with author, citation, PDF metadata, and rights notice.
- `Psilocybin_Design_Theory_Complete.original.tex`: original uploaded source preserved unchanged.
- `references.bib`: machine-readable citation entry for this work.

Build:

```bash
latexmk -pdf -interaction=nonstopmode Psilocybin_Design_Theory_Complete.tex
```
